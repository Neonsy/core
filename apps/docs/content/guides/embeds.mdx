Use `EmbedBuilder` for titles, fields, colors, and footers. Pass the builder into `reply` / `send` / `edit` directly. The SDK serializes it. An embed needs at least one of: title, description, fields, image, or thumbnail.

## Minimal example

```javascript
import { Client, Events, EmbedBuilder } from '@fluxerjs/core';

const client = new Client();

client.on(Events.MessageCreate, async (message) => {
  if (message.content !== '!embed') return;

  const embed = new EmbedBuilder()
    .setTitle('Hello!')
    .setDescription('This is a Fluxer embed.')
    .setColor(0x5865f2)
    .addFields(
      { name: 'Field 1', value: 'Value 1', inline: true },
      { name: 'Field 2', value: 'Value 2', inline: true },
    )
    .setFooter({ text: 'Powered by Fluxer.js' })
    .setTimestamp();

  await message.reply({ embeds: [embed] });
});

await client.login(process.env.FLUXER_BOT_TOKEN);
```

## Description only

No title required:

```javascript
const embed = new EmbedBuilder()
  .setDescription('Still a valid embed.')
  .setColor(0x57f287);

await message.reply({ embeds: [embed] });
```

## Validation

Builder setters reject text and field lists that exceed API limits. The `RangeError` message includes the supplied size and the maximum. Input is not truncated, and a failed setter leaves the previous builder state unchanged.

Text lengths use Fluxer's request normalization. Form feed and U+202E characters are removed, and leading and trailing whitespace is trimmed before validation.

Embed links use lowercase `http://` or `https://` URLs.
Host labels cannot be empty, contain underscores, or start or end with a hyphen, and trailing dots are rejected.
Localhost, TLD-less service names, IPv4, and IPv6 remain available for self-hosted instances.
Image and thumbnail URLs also accept `attachment://filename` when the filename contains only Unicode letters, numbers, marks, underscores, periods, and hyphens.

Fluxer applies message content length, embed count, and aggregate embed limits from server, account, and guild configuration. `MessagePayload` leaves those checks to the API, which returns a `FluxerAPIError` with request context when a configured limit is exceeded.

## Clearing fields

`clearFields()` is gone. Reset with `setFields()` and no args (or an empty array).
